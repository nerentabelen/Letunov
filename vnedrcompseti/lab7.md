# Практическая работа №7: Тестирование компьютерной системы в AIDA64

## Описание программы

**AIDA64 Extreme Edition** — мощный комплекс для диагностики и тестирования Windows-систем, предназначенный для домашних пользователей. Программа предоставляет:

- Инструменты для обзора компонентов и разгона
- Диагностику ошибок и проблем
- Стресс-тесты системы
- Мониторинг датчиков

Программа совместима со всеми современными версиями Windows, включая Windows 8 и Windows Server 2012.

---

## Основные возможности

### Тестирование производительности

AIDA64 включает набор 64-битных тестов для измерения производительности компьютера:

- **Память и кэш** — анализ пропускной способности и задержек оперативной памяти
- **Процессор** — поддержка инструкций MMX, SSE, XOP, FMA, AVX, AVX2; до 32 потоков
- **Диски** — измерение скорости передачи данных HDD, SSD, оптических дисков и флэш-накопителей
- **32-битные версии** для старых процессоров

### Стресс-тесты

Нагружают систему на максимум для проверки стабильности и выявления проблем надёжности. Доступны стресс-тесты:
- Жесткого диска и SSD
- OpenCL GPGPU

### Мониторинг в реальном времени

AIDA64 поддерживает **250 различных датчиков** и отображает:
- Температуру компонентов
- Напряжение питания
- Скорость вращения вентиляторов
- Потребление электроэнергии

Данные могут выводиться в системный трей, OSD-панель, гаджет рабочего стола или на дисплей клавиатуры Logitech G15/G19. Поддерживается логирование данных и экспорт в RivaTuner, Samurai и другие приложения. Программа подаёт оповещения при превышении допустимых значений.

### Диагностика оборудования

- Точная информация о всех компонентах системы без открытия корпуса
- Аппаратный модуль с базой более **150 000 устройств**, постоянно пополняющейся
- Определение текущей частоты процессора
- Статус мониторов (CRT/LCD)
- Выявление проблем через стресс-тесты

### Анализ ПО и операционной системы

**50 страниц информации** о:
- Установленных приложениях и лицензиях
- Антивирусных программах
- Настройках операционной системы
- Запущенных процессах и сервисах
- DLL-файлах и программах автозапуска
- Истории веб-страниц и т. п.

## Контрольные вопросы

### 1. Зачем выполнять стресс-тесты?

Стресс-тесты проверяют **стабильность и надёжность системы** под повышенной нагрузкой. Они:

- Выявляют дефекты компонентов
- Определяют предельные нагрузки, при которых система работает
- Измеряют точки насыщения процессора, памяти и системы ввода-вывода
- Проверяют качество сборки после апгрейда или разгона
- Предотвращают перерастание мелких проблем в серьёзные неисправности

### 2. Зачем нужны программы диагностики?

Диагностические программы предназначены для **оценки состояния ПК** и его компонентов. Они:

- Тестируют и анализируют аппаратные и программные компоненты
- Проверяют состояние жёстких дисков
- Выявляют ошибки оперативной памяти
- Контролируют температуру процессора и другие ключевые показатели
- Предоставляют информацию о комплектующих и периферии
- Позволяют выявить проблемы до критических сбоев
- Помогают контролировать здоровье системы в реальном времени

### 3. Какая программа обладает наибольшим функционалом для тестирования?

**AIDA64** — универсальная утилита с наибольшим функционалом, предоставляющая:

- Детальную информацию о всех компонентах
- Обширные тесты производительности
- Модуль Stress Test для одновременной нагрузки на CPU, GPU и другие компоненты
- Мониторинг температур и напряжения в реальном времени

Другие инструменты (OCCT, Y-Cruncher, Victoria, HDDScan) полезны для специализированных задач, но **AIDA64 остаётся наиболее комплексным решением** для комплексной диагностики ПК.
